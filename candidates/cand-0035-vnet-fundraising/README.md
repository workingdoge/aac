# cand-0035-vnet-fundraising

Defines FUNDRAISE-CLEARING/1 as a Raw non-enshrined application target for
private-balance-sheet fundraising.

## Cargo

- `sites/ledger/specs/applications/FUNDRAISE-CLEARING-1.md` -- new Raw target
  spec for paid subscriptions, private issuer accounting, cap-table root
  updates, VNET amount closure, and restricted token issuance.
- `sites/ledger/specs/applications/README.md` -- application-target index row.

No circuit, registry, contract, concrete VNET curve/profile, external adapter,
or legal/security-token claim is included in this slice.

Intent: Specify FUNDRAISE-CLEARING/1 as a VNET-backed private-balance-sheet
fundraising application target: paid subscriptions update private issuer
books/cap table and gate restricted token issuance, while concrete VNET
curve/profile, circuit, verifier, and vendor adapters remain explicit
follow-ons.

Status: open (pre-threshold).
