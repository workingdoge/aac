# cand-0096-python-poseidon-crosscheck

Intent: Independent Python Poseidon2 cross-check of the PEDERSEN-VECTOR/1 derivation vectors

Status: open (pre-threshold).

## Candidate Scope

This candidate adds an independent Python cross-check for
PEDERSEN-VECTOR/1. The reference implementation lives at
`sites/ledger/specs/profiles/reference/pedersen_vector_1.py` after landing and
uses only the Python standard library.

It implements:

- BN254 scalar-field Poseidon2 permutation with width 4, `R_F = 8`,
  `R_P = 56`, the Barretenberg/Noir linear layers, and exponent-5 S-box;
- the PEDERSEN-VECTOR/1 width-4/rate-3 sponge wrapper used by the beta.19 Noir
  derivation harness, with message length in lane 3;
- `field_of` UTF-8 big-endian string encoding with the profile's `<=31` byte
  fail-closed bound;
- ordered `basis_commitment`, per-generator seeds, try-and-increment,
  Tonelli-Shanks square root over the Grumpkin base field, and canonical even
  `y`.

The numeric vector values are unchanged from cand-0093. The honesty note is
upgraded: the vector remains generated by the Noir-family harness, but is now
independently re-derived and checked by the Python reference.

## Evidence Intent

`eval-self.sh` stages the landing and checks:

- Python regeneration byte-matches `vectors/PEDERSEN-VECTOR-1.json`, and a
  corrupt vector fails;
- a tampered Poseidon2 round constant fails, proving the permutation is
  load-bearing;
- the even-y rule is exercised by the derivation (`G_0`, `G_1`, and `G_2` have
  odd raw square roots before canonicalization);
- the spec/vector honesty clause is upgraded;
- the queue entry is resolved and well-formed.
