This is the presentation console for the private treasury fundraise path: a
captured `fundraise-demo-runner --settle-local --summary` run rendered as a
single operational receipt.

<aac-fundraise-demo></aac-fundraise-demo>

The issuer's balance sheet and cap table move as private roots. ProveKit accepts
the VNET proof, the workflow authorizes the mint, and the local settlement
contract mints receipt tokens while refusing replay. The settlement contract in
this demo verifies the authorizer signature and replay guard; recursive
on-chain VNET verification remains the production verifier target.

## Where it fits

The demo is an implementation path through the application layer:
[BCC/1](/specs/applications/bcc-1/) binds investor and issuer agreement,
[VNET/1](/specs/applications/vnet-1/) clears the amount vectors, and
[FUNDRAISE-CLEARING/1](/specs/applications/fundraise-clearing-1/) binds paid
subscriptions to private issuer books and restricted token issuance. The base
registry still enshrines only TRANSITION/1, NULLIFY/1, and NET/1.
