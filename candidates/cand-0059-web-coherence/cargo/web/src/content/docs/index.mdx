Balance is a proof, not a promise. Entities keep private books, publish provable
balanced-claim roots at names, and anchor ledger roots in a registry that
**refuses unbalanced state**. The core identity is algebraic: double-entry
bookkeeping *is* the Grothendieck group K(M) of amount vectors — which is what
lets a ledger's integrity be checked in zero knowledge.
